# Spider Guy VR - Quest 3 patch

Quest 3 compatibility build of the open-source Spider-Man VR WebXR experience by Oran Gegish (talkol/spiderman).

## What changed
- A-Frame updated from 1.0.3 to 1.6.0.
- A-Frame 1.6.0 recognizes the Meta Quest Touch Plus controller profile used by Quest 3.
- Original game logic, web swinging, city generation, hand animations, and controls are otherwise preserved.
- Binary assets are loaded from the original open-source project at commit `cde3caa9f33d910d8853c7d1b3de7f30a87f9aea` via jsDelivr.
